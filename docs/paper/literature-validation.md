# Literature validation notes

Core records were checked against publisher pages or institutional records and the paper uses only the subset needed to position its narrow contribution. The bibliography includes DOI metadata for traceability.

| Work | Verified record | Relevance and constraint |
|---|---|---|
| Chen et al., DT-assisted RL microservice offloading | [PolyU record / DOI 10.1109/MASS58611.2023.00012](https://research.polyu.edu.hk/en/publications/digital-twin-assisted-reinforcement-learning-for-resource-aware-m/) | Direct evidence that DT+DRL for edge offloading predates this project; broad novelty is not claimed. Conference publication is 2023; arXiv preprint appeared later. |
| Cheng et al., DT-assisted RL resource management | [IEEE Network article / DOI 10.1109/MNET.2024.3438543](https://uwaterloo.ca/scholar/sites/ca.scholar/files/sshen/files/cheng2025toward.pdf) | Describes a DT-enhanced RL framework and case studies. Publication metadata distinguish online publication in 2024 from current issue version in 2025. |
| Bellavista et al., cloud-edge DT microservices | [Future Generation Computer Systems / DOI 10.1016/j.future.2024.03.052](https://www.sciencedirect.com/science/article/pii/S0167739X24001249) | Reports microservice/serverless DT implementations and experimental evaluation; weakens claims that this architecture pattern is novel. |
| Borsatti et al., KubeTwin | [DOI 10.1109/TNSM.2024.3405175](https://doi.org/10.1109/TNSM.2024.3405175) | Kubernetes digital twin precedent. Bibliographic and abstract-level metadata checked; not used to claim a detailed feature-by-feature comparison. |
| Ranjbaran et al., online DT re-placement | [IEEE WF-IoT / DOI 10.1109/WF-IoT62078.2024.10811458](https://ieeexplore.ieee.org/iel8/10811010/10811012/10811458.pdf) | Adjacent topic: placement of the digital twin, distinct from application workload migration. |
| Ali et al., EdgeBus | [Internet of Things / DOI 10.1016/j.iot.2024.101368](https://www.sciencedirect.com/science/article/pii/S2542660524003093) | Direct precedent for Kubernetes co-simulation, migration cost, and testbed scheduling comparisons. |
| Gort et al., AERO | [IEEE TMLCN / DOI 10.1109/TMLCN.2025.3553100](https://xplorestaging.ieee.org/document/10935743) | Forecast-assisted orchestration with real workloads, simulations, and deployment; makes DT-RAM's idle-only comparison preliminary by contrast. |
| Angelopoulos and Bates, conformal prediction tutorial | [arXiv:2107.07511](https://arxiv.org/abs/2107.07511) | General background for finite-sample uncertainty terminology; DT-RAM's own calibration code and insufficient counts determine the reported status. |

Additional titles in `Design.md` were not included because complete publication metadata and the relevance of their specific claims were not established during this review. The paper avoids claiming a systematic literature review or exhaustive novelty search.
